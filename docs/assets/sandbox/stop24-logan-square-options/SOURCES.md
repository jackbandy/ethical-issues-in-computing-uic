# Sources & Licenses — stop 24 (Logan Square) background options

NOTICE: These files were collected by an LLM-based coding system on 2026-10-28 as candidate replacements for `blue-line-stops/stop24-logan-square-a.jpg` (a CDOT / Jacobs Engineering image whose `blue-line-stops/` folder no longer exists, so the Week 10, Day 2 title slides currently point at a missing file). Not yet reviewed. Files 01–05 and 10–15 come from Wikimedia Commons under a CC or public-domain license, each downloaded at up to 3840 px wide (smaller originals kept at full size). Files 06–09 are CDOT renderings of the redesigned station canopy and square (designed with Jacobs Engineering), copied from news coverage; they are all rights reserved and classroom use only, like `altus-renderings/`. Before promoting a file out of `sandbox/`, confirm the license on its Commons page and add an attribution line to the deck's References slide (BY and BY-SA require the author credit; BY-SA also requires naming the license).
