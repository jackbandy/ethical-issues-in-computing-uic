# Sources & Licenses — postcards

Historic postcards of places along the Blue Line, kept for possible slide use. Both files below were collected on 2026-10-28 while looking for Logan Square (stop 24) title images. Each was downloaded unmodified from Wikimedia Commons at full size.

## Files in this directory

- **logan-square-terminal-c1910.png** — [Wikimedia Commons: Logan Square station, c 1900s to 1910s.png](https://commons.wikimedia.org/wiki/File:Logan_Square_station,_c_1900s_to_1910s.png) — License: Public domain — Author: Unknown (Graham Garfield Collection, postcards) — 1024×643 — c. 1900s–1910s — hand-colored postcard of the old elevated Logan Square terminal and yard, captioned "...Terminal, Metropolitan Elevated R.R. Chicago" (left edge of the caption is cropped); low resolution

- **logan-square-northwest-from-l-station-1909.png** — [Wikimedia Commons: Logan Square, Chicago circa 1909 (front).png](https://commons.wikimedia.org/wiki/File:Logan_Square,_Chicago_circa_1909_(front).png) — License: CC0 — Uploaded by victorgrigas — 1334×750 — c. 1909 — postcard captioned "Logan Square Northwest from 'L' Station, Chicago", horse carriages on the boulevard; includes the card's border and postmark
