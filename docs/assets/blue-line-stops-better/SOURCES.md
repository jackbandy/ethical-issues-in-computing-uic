# Sources & Licenses — blue-line-stops-better

This folder contains the subset of Blue Line stop photos selected for actual slide use.
All files are drawn from the larger `blue-line-stops/` collection; see that folder's
`SOURCES.md` for the full inventory and a note on station-artwork copyright.

Files are named `stopNN-<stop>-<letter>.<ext>` matching the same convention as
`blue-line-stops/`, where `NN` is the stop's position along the Blue Line
(Forest Park → O'Hare, per `cta-blue-line-stops.csv`).
