# CTA Grand / Chicago / Division Blue Line station images

Photographs and renderings of the CTA Blue Line stations at Chicago Ave, Grand Ave, and Division St (the Dearborn Subway), from the AltusWorks project page for the renovation: https://altusworks.com/project/cta-grand-chicago-and-division-blue-line-stations-renovation/

The project is part of CTA's "Your New Blue" program launched in 2015. AltusWorks was the street level designer on the F.H. Paschen design/build team, collaborating with Muller2, and adapted their CTA Harrison Red Line station entrance canopy design for these three stations.

Retrieved 2026-10-12 from `https://altusworks.com/wp-content/uploads/2022/12/`. All files are around 2000px on the long edge.
